# Homepage curation

Accepted evidence accumulates under `evidence/*.yaml`. Homepage attention is a separate editorial decision.

`homepage.yaml` records the accepted evidence currently selected for the homepage. Its order is intentional and represents presentation order.

Evidence contributors should not modify this directory as part of an evidence proposal. A contribution may recommend promotion in discussion, but promotion is decided on the editorial surface and does not change whether the record remains accepted evidence.

For now this manifest records the existing homepage selection only. A later generator change will use it as the canonical input for the homepage evidence section.
