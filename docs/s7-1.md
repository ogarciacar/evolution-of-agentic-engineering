# S7.1 — Model claims

S7 moves the research system from accumulating evidence to evaluating the working model.

## Purpose

Make the propositions behind the Evolution of Agentic Engineering explicit enough to be challenged by evidence.

`model/claims.yaml` is the canonical claim set. It is separate from the evidence corpus: claims describe the working model; evidence records describe observations and their interpretation.

## Contract

Each claim has:

- a stable `Cxx` identity;
- the model stage it concerns;
- a short title;
- the proposition being evaluated;
- an explicit description of evidence that would challenge it.

The initial claim set contains one proposition for each model stage, in model order:

1. Apparition — agents become viable engineering actors.
2. Mutation — agent configurations proliferate.
3. Selection — engineering environments determine what can scale.
4. Cooperation — fit agents compose into complex workflows.
5. Specialization — repeated cooperation produces differentiated capabilities.

## Boundary

S7.1 does not score the claims, modify evidence records, or infer relationships between existing evidence and claims. Those mappings must be explicit before claim-level evaluation can be derived.

The claims are working propositions, not conclusions. A claim remains open to refinement or rejection as the corpus changes.
