Decide what deserves homepage attention

A comparative editorial protocol for deciding whether accepted evidence should replace one of the currently promoted homepage records. Promotion allocates attention; it does not determine whether evidence is true or belongs in the evidence base.

Entry condition

Accepted evidence first. Promotion second.

Only evidence already accepted into evidence/*.yaml is eligible for promotion. The evidence assessment and the homepage decision remain separate.

Evidence acceptance asks: Does this belong in the evidence base?

Promotion asks: Does this candidate make the current homepage evidence set better?
The protocol

Compare the candidate with every incumbent.

01 · ACQUIRE

Read the candidate evidence record, the current homepage curation manifest and each promoted evidence record.

02 · COMPARE

Compare the candidate against every incumbent. Do not evaluate it only in isolation.

03 · IDENTIFY

State the candidate's unique contribution: what does it add that the homepage does not already represent well?

04 · TEST

Ask whether replacing any incumbent produces a more informative, diverse or challenging representation of the evidence base.

05 · RECOMMEND

Return exactly one recommendation: PROMOTE or DO NOT PROMOTE. If promoting, name exactly one replacement.

06 · BOUND

State the caution: what could make the recommendation misleading, unstable or overly influenced by novelty?

Comparative dimensions

Judgment, not a ranking function.

Use these dimensions to structure reasoning. Do not turn them into a numeric score.

Evidence strength

How concrete, inspectable and bounded are the observations?

Model significance

Does the evidence support, refine, contradict or expose an important boundary in the model?

Distinctiveness

Does it add a stage, condition, contradiction or perspective not already represented strongly?

Scale significance

Does it reveal consequential behavior or constraints at meaningful engineering scale without inflating capability into demonstrated scale?

One candidate → one editorial recommendation

Agent instruction

A prompt you can use anywhere

Assess an accepted evidence record for homepage promotion using https://agenticengineering.science/promote.html.

Read the candidate YAML record, curation/homepage.yaml, and every evidence record currently promoted there. Compare the candidate against each incumbent. Recommend exactly one of PROMOTE or DO NOT PROMOTE. If PROMOTE, identify exactly one incumbent to replace and explain why that replacement improves the homepage evidence set.

Do not use a numeric score. Recency alone is not a reason for promotion. Large numbers alone are not a reason for promotion. Evidence that contradicts or refines the model may deserve promotion over evidence that merely supports it. Do not modify curation or publish the recommendation without explicit maintainer approval.

Candidate: [EVIDENCE ID]
Authority boundary

The agent proposes attention. The maintainer allocates it.

A promotion assessment never changes curation/homepage.yaml by itself. If the recommendation is PROMOTE, the agent presents the proposed replacement and waits for explicit maintainer approval. Only then should a curation change be prepared.

Contributor proposes truth claims ↓ Reviewer accepts evidence ↓ Agent proposes attention ↓ Maintainer allocates attention ↓ Generator publishes
Editorial rules

Keep attention allocation independent from evidence acceptance.

  • Promotion is comparative editorial judgment, not another evidence verdict.
  • A candidate should be promoted only when replacing an incumbent produces a more informative, diverse or challenging homepage set.
  • Recency alone is not a reason for promotion.
  • Large scale numbers alone are not a reason for promotion.
  • Contradicting or refining evidence may be more homepage-worthy than additional supporting evidence.
  • Do not infer promotion from SUPPORTS, REFINES or any other model implication.
  • Do not let an evidence record determine its own homepage publication status.
  • Compare the candidate against every incumbent before recommending a replacement.
  • The agent must never merge its own promotion recommendation.
